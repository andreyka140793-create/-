| Файл | Размер кадра | Кадров | Порядок кадров |
|------|----------------|--------|----------------|
| `sanych.png` | 48×64 | 6 | 0 idle, 1–4 run, 5 jump |
| `neighbor.png` | 44×58 | 3 | walk cycle |
| `cat.png` | 48×36 | 3 | walk cycle |

Ширина листа = frameWidth × количество кадров.

- Персонажи смотрят **вправо**
